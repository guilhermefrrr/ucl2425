# ucl2425
This project provides comprehensive performance data for every league phase fixture in the UEFA Champions League 2024/25 season. Utilizing tools such as Python, Jupyter Notebook, and NumPy, it enables in-depth analysis and visualization of match statistics and trends across all participating teams
